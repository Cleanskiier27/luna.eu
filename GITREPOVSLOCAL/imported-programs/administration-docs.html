2. Local operation

cd GITREPOVSLOCAL
python -m http.server 8000
# Open http://127.0.0.1:8000/admin.html

Run through localhost so module loading, fetch requests, and browser APIs have a consistent origin.

5. Cloud administration

  1. Use an authorized project administrator account for Google Cloud IAM.
  2. Confirm the target project before enabling Vertex AI or granting roles.
  3. Prefer predefined least-privilege roles over broad Owner/Editor grants.
  4. Keep service-account keys and API tokens outside browser files.
  5. Use environment secrets or workload identity for automated POST operations.

A static hosted page cannot grant IAM roles, enable APIs, authenticate to Azure, or write physical devices. Complete those actions in the authenticated provider console or approved local tooling.

6. Safe device and flash administration

  • Record target identity and capacity before any write.
  • Require an explicit second confirmation for destructive actions.
  • Verify checksums after imaging.
  • Never automate physical-device selection based only on a path or letter.
  • Keep flash commands local and preserve a tested recovery image.
